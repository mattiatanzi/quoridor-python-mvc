<h2 id=ManifestoTeam> Manifesto del team </h2>

- **Risolvere le build rotte** ha massima priorità 
- **Partecipare alle revisioni delle issue** è la seconda priorità
- **Migliorare la velocità del team** è più importante che migliorare quella individuale
- **Non arrivare in ritardo** alle riunioni del team
- **Chiedere aiuto** quando c'è ne sarà bisogno
- **Offrire aiuto** quando richiesto
- **Essere sempre onesto**
- **Se non si crede che qualcosa sia possibile**, lo si dirà **senza esitazione**
- **Aggiornare sempre** la directory di lavoro *con git fetch*
- **Non modificare** direttamente il main, sempre con l'utilizzo dei branch
- Rispetta il **workflow**
- **Rispettare tutti i membri del team**
- **Essere sempre aperti a feedback** quando avviene una review

 

<h2 id = InserimentoCommit>Inserimento Commit</h2>

- Separare il **titolo** dalla descrizione
- **Titolo** con meno di 50 caratteri
- **Titolo** con lettera maiuscola iniziale
- **Non chiudere il titolo** con il punto
- Utilizare uno **stile imperativo** 
- Se c'è bisogno di ulteriori informazioni **aggiungere anche una descrizione** *utilizzando git commit -F file.md*
- Nella descrizione dopo **72 caratteri a capo**
- Spiegare **cosa è stato fatto** rispetto al come
- Eseguire **commit frequenti** 
- Non eseguire **commit inutili**
- **Aggiornare frequentemente** la repository su git hub, *utilizzando git push origin nomeissue*
